## 説明

忍の一族を率いましょう。山奥に隠れ里を築き、五十種類の戦士を鍛え、ライバルを偵察して、煙と破壊工作で襲撃します。

**隠れ里を築く**

- 天守閣をLv.1からLv.15まで強化し、建物、壁、防衛設備を解放します。
- 建物にはそれぞれ役目があります：小判鋳造所、棚田、蔵、修行道場、櫓、罠。
- 襲撃者がその前を通らざるを得ないように防衛設備を配置しましょう。

**五十種類の戦士を鍛える**

- 忍や苦無の使い手から、凧の襲撃者、破壊工作員、攻城砲手まで、それぞれに役割があります。
- 修行道場で研究して、戦士を強くしましょう。

**作戦を立てて襲撃する**

- 戦士は潜入口からしか入れません。進路と、それを守る櫓を偵察しましょう。
- 戦士が櫓の射程に入るときに煙玉を投げ、破壊工作員を送って防衛設備を妨害します。
- よく考えた攻撃は、大軍にも勝ります。

**仲間と遊ぶ**（オンライン）

- 同盟に入って、チャットしたり、戦士をリクエストしたり送ったりしましょう。
- 毎週の同盟戦で戦いましょう。
- フレンドを追加して手合わせを挑み、最大4人の徒党を組んで徒党戦に挑みましょう。
- 名誉のリーグと戦力ランキングを駆け上がりましょう。

**影の試練**

- 果てしなく続く砦の試練。層を進むごとに難しくなり、各層の報酬は一度だけ受け取れます。

**公正なプレイ**

- 無料の日替わり宝箱は、開ける前に確率を確認できます。ランダムなものは販売していません。
- コンピューターが生成した相手には、必ずそのことが表示されます。
- 18歳未満のプレイヤーには支出上限があり、お知らせは自分で選んだものだけ、オンにするまでオフです。

Kagemura は無料でダウンロードして遊べます。すべての建物、戦士、天守閣のレベル、ゲームモードはお金を払わずに利用でき、広告もありません。プレミアム通貨の翡翠は、プレイ（目標、リーグ、日替わり宝箱、シーズン巻物の無料枠）で少しずつ手に入り、購入することもできます。一部のコンテンツは有料でのみ販売しています：シーズン巻物のプレミアム枠（追加の報酬、シーズン中の建設の高速化、天守閣の外観「灯籠祭り」）と、期間限定の翡翠と資源のパックです。
