# ગુજરાતી સ્ટોર માહિતી — Kagemura: Ninja Clans

App Store અને Google Play (gu-IN) માટે તૈયાર કરેલું લખાણ, ગેમની જ ભાષા અને શબ્દો સાથે (`locales/gu/TERMS.md`). કિંમતો અને ખરીદીની સ્ક્રીન દરેક સ્ટોર પોતે બતાવે છે. સ્ટોર માહિતી અને સ્ક્રીનશૉટ પ્રકાશિત કરવાં એ રિલીઝ સમયનું કામ છે, સ્થાનિક બિલ્ડનો ભાગ નથી. આ લખાણ હજુ કોઈ સ્ટોરના કન્સોલમાં મુકાયું નથી અને મૂળ ગુજરાતી ભાષી વ્યક્તિએ તેની સમીક્ષા કરી નથી.

- નામ: **Kagemura: Ninja Clans**
- App Store ઉપશીર્ષક: **પહાડોમાં છુપાયેલું નિન્જા ગામ**
- Google Play ટૂંકું વર્ણન: **છુપાયેલું ગામ બનાવો, યોદ્ધાઓને તાલીમ આપો, હરીફ કુળો પર ધાડ પાડો**
- પ્રચાર લખાણ: **તમારા કુળને ક્યારેય પૂરી ન થતી છાયા કસોટીઓમાંથી આગળ લઈ જાઓ. ધુમાડો, તોડફોડ અને યોજના તાકાતને હરાવે છે.**
- કીવર્ડ: `નિન્જા,કુળ,ગામ,ધાડ,કિલ્લો,યુદ્ધ,ninja,shinobi`

## વર્ણન

નિન્જા કુળનું નેતૃત્વ કરો. પહાડોમાં છુપાયેલું ગામ બનાવો, પચાસ પ્રકારના યોદ્ધાઓને તાલીમ આપો, હરીફોની જાસૂસી કરો અને ધુમાડા તથા તોડફોડ સાથે તેમના પર ધાડ પાડો.

**છુપાયેલું ગામ બનાવો**

- કુળ કિલ્લાને સ્તર 1 થી 15 સુધી વધારો અને નવી ઇમારતો, દીવાલો અને સંરક્ષણ ખોલો.
- દરેક ઇમારતનું કામ નક્કી છે: ટંકશાળ, પગથિયાંવાળું ખેતર, ખજાનો, તાલીમ ડોજો, ટાવર અને ફાંદા.
- સંરક્ષણ એવી રીતે ગોઠવો કે ધાડપાડુઓએ તેમાંથી જ પસાર થવું પડે.

**પચાસ યોદ્ધાઓને તાલીમ આપો**

- શિનોબી અને કુનાઈ નિષ્ણાતથી લઈને પતંગ ધાડપાડુ, તોડફોડિયા અને ઘેરાબંધી તોપચી સુધી, દરેકની પોતાની ભૂમિકા.
- તાલીમ ડોજોમાં સંશોધન કરીને દરેક યોદ્ધાને વધુ મજબૂત બનાવો.

**યોજના બનાવો, પછી ધાડ પાડો**

- યોદ્ધા ફક્ત ઘૂસણખોરી બિંદુઓમાંથી જ અંદર આવી શકે છે: રસ્તા અને તેના પર નજર રાખતા ટાવરની જાસૂસી કરો.
- યોદ્ધા ટાવરની પહોંચમાં આવે ત્યારે ધુમાડા બોમ્બ ફેંકો, અને સંરક્ષણને જામ કરવા તોડફોડિયો મોકલો.
- સારી રીતે વિચારેલો હુમલો મોટી સેનાને પણ હરાવે છે.

**સાથે રમો** (ઑનલાઇન)

- ગઠબંધનમાં જોડાઓ: વાત કરો, યોદ્ધા માંગો અને સાથીઓને મોકલો.
- દર અઠવાડિયે ગઠબંધન યુદ્ધમાં લડો.
- મિત્રો ઉમેરો, તેમને મૈત્રી મુકાબલા માટે પડકાર આપો, અને ટોળકી યુદ્ધ માટે ચાર જણ સુધીની ટોળકી બનાવો.
- સન્માન લીગ અને શક્તિ રેન્કિંગમાં ઉપર ચડો.

**છાયા કસોટીઓ**

- કિલ્લાઓની ક્યારેય પૂરી ન થતી શ્રેણી. દરેક પડાવ એક જ વાર ઇનામ આપે છે, અને આગળનો વધુ અઘરો હોય છે.

**ન્યાયી રમત**

- મફત દૈનિક પેટી, ખોલતાં પહેલાં તેની સંભાવના બતાવેલી. કંઈ પણ રેન્ડમ વેચાતું નથી.
- કમ્પ્યુટર-નિર્મિત હરીફો હંમેશાં સ્પષ્ટ રીતે દર્શાવેલા હોય છે.
- 18 વર્ષથી નાના ખેલાડીઓ માટે ખર્ચ મર્યાદા, અને તમે પસંદ કરો તે સૂચનાઓ (તમે ચાલુ કરો ત્યાં સુધી બંધ).

Kagemura ડાઉનલોડ કરવા અને રમવા માટે મફત છે: દરેક ઇમારત, યોદ્ધો, કિલ્લા સ્તર અને રમતનો પ્રકાર પૈસા ચૂકવ્યા વગર મેળવી શકાય છે, અને કોઈ જાહેરાત નથી. જેડ, એટલે કે પ્રીમિયમ ચલણ, રમતાં રમતાં થોડું થોડું મળે છે (સિદ્ધિઓ, લીગ, દૈનિક પેટી અને સીઝન ઓળિયાનો મફત માર્ગ) અને ખરીદી પણ શકાય છે. કેટલીક વસ્તુઓ ફક્ત સાચા પૈસાથી જ મળે છે: સીઝન ઓળિયાનો પ્રીમિયમ માર્ગ (વધારાનાં ઇનામ, આખી સીઝન દરમિયાન ઝડપી બાંધકામ અને કિલ્લાનો "ફાનસ ઉત્સવ" દેખાવ) અને જેડ તથા સંસાધનોનાં મર્યાદિત-સમયનાં બંડલ.

## રિલીઝ લિંક

પ્રકાશિત ગેમના સરનામા પછી `/gu/support.html`, `/gu/privacy.html` અને `/gu/community.html` ઉમેરો. સર્વરનું ફોર્મ `/account/delete?lang=gu` સ્વીકારે છે. જાપાનનાં કાનૂની પેજના ગુજરાતી અનુવાદ `/gu/tokushoho.html` અને `/gu/shikin-kessai.html` છે. સેવાની શરતો અને કાનૂની પેજ પ્રકાશક વિગતો ભરીને લાગુ ન કરે ત્યાં સુધી ડ્રાફ્ટ રહે છે. રિલીઝના નિયમો [RELEASE.md](../RELEASE.md) માં છે.

## રિલીઝ નોંધ

Kagemura હવે ગુજરાતીમાં ઉપલબ્ધ છે. સ્ક્રીન, માર્ગદર્શન, ઇમારતો, યોદ્ધા, લડાઈ, સૂચનાઓ અને મદદ પેજ ગુજરાતીમાં દેખાય છે. ભાષા સેટિંગ્સ → ભાષા માં બદલો. તમારું ગામ અને ખેલાડીનું નામ એમ જ રહે છે.

ગુજરાતી સ્ક્રીનશૉટ: `npm run build && npm run store:screenshots -- --language=gu` (Playwright, Chromium અને ગુજરાતી ફૉન્ટ જરૂરી; પ્રોગ્રામ `CHROMIUM_PATH` થી પસંદ કરી શકાય છે)
