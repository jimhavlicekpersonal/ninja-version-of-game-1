# മലയാളം സ്റ്റോർ വിവരങ്ങൾ — Kagemura: Ninja Clans

App Store, Google Play (ml-IN) എന്നിവയ്ക്കായി തയ്യാറാക്കിയ വാചകം; കളിയിലെ അതേ ഭാഷയും പദങ്ങളും (`locales/ml/TERMS.md`). വിലകളും വാങ്ങൽ സ്ക്രീനുകളും ഓരോ സ്റ്റോറും തന്നെ കാണിക്കുന്നു. സ്റ്റോർ വിവരങ്ങളും സ്ക്രീൻഷോട്ടുകളും അപ്‌ലോഡ് ചെയ്യുന്നത് റിലീസ് സമയത്തെ ജോലിയാണ്, ലോക്കൽ ബിൽഡിന്റെ ഭാഗമല്ല. ഈ വാചകം ഇതുവരെ ഒരു സ്റ്റോർ കൺസോളിലും ചേർത്തിട്ടില്ല; മലയാളം മാതൃഭാഷക്കാരായ ആരും ഇത് പരിശോധിച്ചിട്ടില്ല.

- പേര്: **Kagemura: Ninja Clans**
- App Store ഉപശീർഷകം: **മലകളിൽ മറഞ്ഞ നിൻജ ഗ്രാമം**
- Google Play ചെറുവിവരണം: **മറഞ്ഞ ഗ്രാമം പണിയുക, യോദ്ധാക്കളെ പരിശീലിപ്പിക്കുക, എതിർ കോട്ടകൾ റെയ്ഡ് ചെയ്യുക**
- പ്രൊമോഷണൽ വാചകം: **അവസാനമില്ലാത്ത നിഴൽ പരീക്ഷകളിലൂടെ നിങ്ങളുടെ കുലത്തെ നയിക്കുക. പുകയും അട്ടിമറിയും നല്ല പദ്ധതിയും വെറും ശക്തിയെ തോൽപ്പിക്കും.**
- കീവേഡുകൾ: `ninja,shinobi,നിൻജ,കുലം,കോട്ട,യുദ്ധം,സഖ്യം`

## വിവരണം

ഒരു നിൻജ കുലത്തെ നയിക്കുക. മലകളിൽ മറഞ്ഞ ഗ്രാമം നിർമ്മിക്കുക, അമ്പത് തരം യോദ്ധാക്കളെ പരിശീലിപ്പിക്കുക, എതിരാളികളെ നിരീക്ഷിക്കുക, പിന്നെ പുകയും അട്ടിമറിയുമായി റെയ്ഡ് ചെയ്യുക.

**മറഞ്ഞ ഗ്രാമം നിർമ്മിക്കുക**

- കുലക്കോട്ട ലെവൽ 1 മുതൽ 15 വരെ ഉയർത്തി പുതിയ കെട്ടിടങ്ങളും മതിലുകളും പ്രതിരോധങ്ങളും തുറക്കുക.
- ഓരോ കെട്ടിടത്തിനും സ്വന്തം ജോലി: നാണയശാല, തട്ടുപാടം, ഖജനാവ്, പരിശീലന ഡോജോ, ഗോപുരങ്ങൾ, കെണികൾ.
- റെയ്ഡർമാർ നിങ്ങളുടെ പ്രതിരോധങ്ങളിലൂടെ തന്നെ കടന്നുവരേണ്ട വിധം അവ വിന്യസിക്കുക.

**അമ്പത് തരം യോദ്ധാക്കളെ പരിശീലിപ്പിക്കുക**

- ഷിനോബിയും കുനായ് നിപുണരും മുതൽ പട്ടം റെയ്ഡർ, അട്ടിമറിക്കാർ, ഉപരോധ പീരങ്കിപ്പട വരെ, ഓരോന്നിനും സ്വന്തം പങ്ക്.
- പരിശീലന ഡോജോയിലെ ഗവേഷണം യോദ്ധാക്കളെ കൂടുതൽ ശക്തരാക്കുന്നു.

**പദ്ധതിയോടെ റെയ്ഡ് ചെയ്യുക**

- യോദ്ധാക്കൾ നുഴഞ്ഞുകയറ്റ കേന്ദ്രങ്ങളിലൂടെ മാത്രമേ അകത്ത് കടക്കൂ. വഴികളും അവ കാക്കുന്ന ഗോപുരങ്ങളും മുൻകൂട്ടി നിരീക്ഷിക്കുക.
- യോദ്ധാക്കൾ ഗോപുരത്തിന്റെ പരിധിയിൽ എത്തുമ്പോൾ പുകബോംബ് എറിയുക, ഒരു പ്രതിരോധം സ്തംഭിപ്പിക്കാൻ അട്ടിമറിക്കാരെ അയയ്ക്കുക.
- നന്നായി ആസൂത്രണം ചെയ്ത ആക്രമണം വലിയ സൈന്യത്തെയും തോൽപ്പിക്കും.

**ഒരുമിച്ച് കളിക്കുക** (ഓൺലൈൻ)

- ഒരു സഖ്യത്തിൽ ചേർന്ന് ചാറ്റ് ചെയ്യുക, യോദ്ധാക്കളെ ചോദിക്കുക, കുലാംഗങ്ങൾക്ക് അയച്ചുകൊടുക്കുക.
- ആഴ്ചതോറുമുള്ള സഖ്യയുദ്ധത്തിൽ പോരാടുക.
- സുഹൃത്തുക്കളെ ചേർത്ത് സൗഹൃദ ദ്വന്ദ്വത്തിന് വെല്ലുവിളിക്കുക; പരമാവധി 4 പേരുള്ള പടയായി പടയുദ്ധങ്ങളിൽ പങ്കെടുക്കുക.
- ബഹുമതി ലീഗുകളിലും ശക്തി റാങ്കിങ്ങിലും മുന്നേറുക.

**നിഴൽ പരീക്ഷകൾ**

- അവസാനമില്ലാത്ത കോട്ടകളുടെ ഏണി. ഓരോ ഘട്ടവും കൂടുതൽ കഠിനം, ഓരോ ഘട്ടത്തിനും സമ്മാനം ഒരിക്കൽ മാത്രം.

**ന്യായമായ കളി**

- സൗജന്യ ദിവസപ്പെട്ടി, തുറക്കുന്നതിന് മുൻപേ സാധ്യതകൾ കാണിക്കുന്നു; ക്രമരഹിതമായ ഒന്നും ഒരിക്കലും വിൽക്കുന്നില്ല.
- കമ്പ്യൂട്ടർ നിർമ്മിത എതിരാളികളെ എപ്പോഴും അങ്ങനെ തന്നെ അടയാളപ്പെടുത്തുന്നു.
- 18 വയസ്സിൽ താഴെയുള്ളവർക്ക് ചെലവ് പരിധി; നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ഓർമ്മപ്പെടുത്തലുകൾ മാത്രം, നിങ്ങൾ ഓണാക്കുന്നതുവരെ അവ ഓഫായിരിക്കും.

Kagemura ഡൗൺലോഡ് ചെയ്യാനും കളിക്കാനും സൗജന്യമാണ്: എല്ലാ കെട്ടിടവും യോദ്ധാവും കോട്ട ലെവലും കളിരീതിയും പണം നൽകാതെ നേടാം, പരസ്യങ്ങളില്ല. പ്രീമിയം കറൻസിയായ ജേഡ് കളിക്കുന്നതിലൂടെ അല്പാല്പമായി ലഭിക്കുന്നു (നേട്ടങ്ങൾ, ലീഗുകൾ, ദിവസപ്പെട്ടി, സീസൺ ചുരുളിന്റെ സൗജന്യ പാത), വാങ്ങാനും കഴിയും. ചിലത് യഥാർത്ഥ പണത്തിന് മാത്രമേ വിൽക്കുന്നുള്ളൂ: സീസൺ ചുരുളിന്റെ പ്രീമിയം പാത (അധിക സമ്മാനങ്ങൾ, സീസൺ മുഴുവൻ വേഗത്തിലുള്ള നിർമ്മാണം, "റാന്തൽ ഉത്സവം" കോട്ട രൂപം), പരിമിതകാല ജേഡ്, വിഭവ പായ്ക്കുകൾ.

## റിലീസ് ലിങ്കുകൾ

പ്രസിദ്ധീകരിച്ച കളിയുടെ വിലാസത്തിനൊപ്പം `/ml/support.html`, `/ml/privacy.html`, `/ml/community.html` എന്നിവ ചേർത്ത് ഉപയോഗിക്കുക. സെർവർ ഫോം `/account/delete?lang=ml` സ്വീകരിക്കുന്നു. ജാപ്പനീസ് നിയമ പേജുകളുടെ മലയാളം വിവർത്തനങ്ങൾ `/ml/tokushoho.html`, `/ml/shikin-kessai.html` എന്നിവയാണ്. സേവന നിബന്ധനകളും നിയമ പേജുകളും നടത്തിപ്പുകാർ വിവരങ്ങൾ പൂരിപ്പിച്ച് പ്രാബല്യത്തിലാക്കുന്നതുവരെ കരടുകൾ മാത്രം. റിലീസ് നിയമങ്ങൾ [RELEASE.md](../RELEASE.md)-ൽ ഉണ്ട്.

## റിലീസ് കുറിപ്പുകൾ

Kagemura ഇപ്പോൾ മലയാളത്തിലും ലഭ്യമാണ്. സ്ക്രീനുകൾ, പരിശീലനം, കെട്ടിടങ്ങൾ, യോദ്ധാക്കൾ, യുദ്ധങ്ങൾ, അറിയിപ്പുകൾ, സഹായ പേജുകൾ എല്ലാം മലയാളത്തിൽ കാണാം. ക്രമീകരണങ്ങൾ → ഭാഷ എന്നതിൽ ഭാഷ മാറ്റാം. നിങ്ങളുടെ ഗ്രാമവും കളിക്കാരന്റെ പേരും മാറില്ല.

മലയാളം സ്ക്രീൻഷോട്ടുകൾ: `npm run build && npm run store:screenshots -- --language=ml` (Playwright, Chromium, മലയാളം ഫോണ്ട് എന്നിവ വേണം; പ്രോഗ്രാം `CHROMIUM_PATH` വഴി നൽകാം)
