# 한국어 스토어 등록 정보 — Kagemura: Ninja Clans

App Store와 Google Play(ko-KR)용으로 준비한 문구예요. 게임과 같은 해요체와 같은 용어(`locales/ko/TERMS.md`)를 써요. 가격과 구매 화면은 각 스토어가 표시해요. 이 등록 정보와 스크린샷의 게시는 출시 작업이며 로컬 빌드에는 포함되지 않아요. 이 문구는 아직 어떤 스토어 콘솔에도 제출되지 않았고, 한국어 원어민의 검토도 받지 않았어요.

- 이름: **Kagemura: Ninja Clans**
- App Store 부제: **산속에 숨은 닌자 마을**
- Google Play 간단한 설명: **숨겨진 마을을 세우고, 전사를 훈련하고, 라이벌의 요새를 습격하세요.**
- 홍보 텍스트: **가문을 이끌고 끝없이 이어지는 그림자 시련에 도전하세요. 힘보다 연막, 교란, 지략이 이겨요.**
- 키워드: `닌자,시노비,가문,마을,전략,습격,방어,탑,성,전쟁,동맹,요새`

## 설명

닌자 가문을 이끄세요. 산속에 숨겨진 마을을 세우고, 오십 종류의 전사를 훈련하고, 라이벌을 정찰한 뒤 연막과 교란으로 습격하세요.

**숨겨진 마을을 세우세요**

- 가문 본성을 Lv.1부터 Lv.15까지 업그레이드해 건물, 성벽, 방어 시설을 여세요.
- 건물마다 역할이 있어요: 코인 주조소, 계단식 논, 창고, 수련 도장, 탑, 함정.
- 습격자가 그 앞을 지나갈 수밖에 없도록 방어 시설을 배치하세요.

**오십 종류의 전사를 훈련하세요**

- 시노비와 쿠나이 명수부터 연 습격자, 교란병, 공성 포병까지, 모두 각자의 역할이 있어요.
- 수련 도장에서 연구해 전사를 강하게 만드세요.

**작전을 세워 습격하세요**

- 전사는 침투 지점으로만 들어갈 수 있어요. 경로와 그 길을 지키는 탑을 정찰하세요.
- 전사가 탑의 사거리에 들어설 때 연막탄을 던지고, 교란병을 보내 방어 시설을 멈추세요.
- 잘 짠 공격은 대군보다 강해요.

**함께 플레이하세요**(온라인)

- 동맹에 가입해 채팅하고, 전사를 요청하고 보내세요.
- 매주 열리는 동맹전에서 싸우세요.
- 친구를 추가해 대련을 신청하고, 최대 4명의 무리를 만들어 무리전에 도전하세요.
- 명예 리그와 전투력 순위를 올라가세요.

**그림자 시련**

- 끝없이 이어지는 요새의 시련. 층을 오를수록 어려워지고, 층마다 보상은 한 번씩 받아요.

**공정한 플레이**

- 무료 일일 상자는 열기 전에 확률을 확인할 수 있어요. 무작위 상품은 판매하지 않아요.
- 컴퓨터가 만든 상대에는 항상 그렇다고 표시돼요.
- 18세 미만 플레이어에게는 지출 한도가 있고, 알림은 직접 고른 것만, 켜기 전까지는 꺼져 있어요.

Kagemura는 무료로 내려받아 플레이할 수 있어요. 모든 건물, 전사, 본성 레벨, 게임 모드는 돈을 내지 않고 이용할 수 있고, 광고도 없어요. 프리미엄 화폐인 비취는 플레이(목표, 리그, 일일 상자, 시즌 두루마리의 무료 트랙)로 조금씩 얻을 수 있고, 구매할 수도 있어요. 일부 콘텐츠는 유료로만 판매해요: 시즌 두루마리의 프리미엄 트랙(추가 보상, 시즌 동안 건설 가속, 본성 외형 “등불 축제”)과 기간 한정 비취·자원 팩이에요.

## 출시용 링크

공개된 게임 주소에 `/ko/support.html`, `/ko/privacy.html`, `/ko/community.html`을 붙여 쓰세요. 서버 양식은 `/account/delete?lang=ko`를 지원해요. 일본 법정 페이지의 한국어 번역은 `/ko/tokushoho.html`과 `/ko/shikin-kessai.html`이에요. 서비스 약관과 법정 페이지는 운영자가 정보를 기재하고 채택할 때까지 초안이에요. 게시 요건은 [RELEASE.md](../RELEASE.md)에 있어요.

## 출시 노트

Kagemura가 한국어를 지원해요. 인터페이스, 튜토리얼, 건물, 전사, 전투, 알림, 도움말 페이지가 한국어로 표시돼요. 언어는 설정 → 언어에서 바꿀 수 있어요. 마을과 플레이어 이름은 그대로예요.

한국어 스크린샷: `npm run build && npm run store:screenshots -- --language=ko`(Playwright와 Chromium, 그리고 한국어 글꼴이 필요해요. `CHROMIUM_PATH`로 실행 파일을 지정할 수 있어요).
