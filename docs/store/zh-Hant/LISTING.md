# 繁體中文商店資訊 — Kagemura: Ninja Clans

為 App Store 與 Google Play（zh-TW，也用於 zh-HK）準備的文字，語言和用語與遊戲內相同（`locales/zh-Hant/TERMS.md`）。價格和購買畫面由各商店顯示。上架資訊和截圖屬於上市作業，不在本機建置內。這些文字尚未送進任何商店後台，也尚未經過以繁體中文為母語者的審閱。

- 名稱：**Kagemura: Ninja Clans**
- App Store 副標題：**山中隱密的忍者村**
- Google Play 簡短說明：**建立隱村、訓練戰士、突襲對手的據點**
- 宣傳文字：**帶領你的忍族挑戰永無止境的暗影試煉。煙霧、破壞與智謀勝過蠻力。**
- 關鍵字：`忍者,忍族,村莊,策略,突襲,防禦,塔防,城堡,戰爭,同盟,天守閣,煙霧彈`

## 說明

帶領一支忍族，在山中建立隱密的村莊，訓練五十種戰士，偵察對手，再用煙霧和破壞發動突襲。

**建立隱村**

- 把天守閣從 1 級升到 15 級，解鎖建築、城牆和防禦設施。
- 每座建築都有自己的用途：鑄幣坊、梯田、金庫、修行道場、箭塔和陷阱。
- 布置防禦設施，讓突襲者必須從它們面前經過。

**訓練五十種戰士**

- 從忍者、苦無高手，到風箏突襲者、破壞者和攻城砲手，每一種都有自己的角色。
- 在修行道場研究，讓戰士變得更強。

**計畫，然後突襲**

- 戰士只能從潛入點進入。先偵察路線和守住路線的箭塔。
- 戰士走進箭塔射程時丟出煙霧彈，再派破壞者讓防禦設施停擺。
- 想清楚的進攻能贏過更大的軍隊。

**一起玩**（線上）

- 加入同盟聊天，請求並捐贈戰士。
- 每週參加同盟戰。
- 加好友、發起友誼切磋，組成最多 4 人的幫派參加幫派戰。
- 爬上榮譽聯賽和戰力排行榜。

**暗影試煉**

- 一座永無止境的據點階梯，每一層都更難，每一層的獎勵只發一次。

**公平的遊戲**

- 免費的每日寶箱在開啟前先顯示機率；不販售任何隨機物品。
- 電腦生成的對手一定會標示出來。
- 未滿 18 歲的玩家有消費上限；通知只有你選擇的那些，在你開啟前都是關閉的。

Kagemura 可免費下載和遊玩。所有建築、戰士、天守閣等級和遊戲模式都不需付費就能使用，而且沒有廣告。進階貨幣翡翠可透過遊玩慢慢取得（目標、聯賽、每日寶箱和賽季卷軸的免費路線），也可以購買。有些內容只能購買：賽季卷軸的進階路線（額外獎勵、整個賽季建造更快，以及「燈籠祭」天守閣外觀），以及限時的翡翠和資源組合。

## 版本資訊

Kagemura 現在支援繁體中文。畫面、教學、建築、戰士、戰鬥、通知和說明頁面都會以繁體中文顯示。可在「設定 → 語言」切換。你的村莊和玩家名稱不會改變。

繁體中文截圖：`npm run build && npm run store:screenshots -- --language=zh-Hant`（需要 Playwright、Chromium 和繁體中文字型；可用 `CHROMIUM_PATH` 指定程式）
