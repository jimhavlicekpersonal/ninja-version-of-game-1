# Imininingwane yesitolo ngesiZulu — Kagemura: Ninja Clans

Umbhalo olungiselelwe i-App Store ne-Google Play (zu), ngolimi namagama afanayo nalawo asemdlalweni (`locales/zu/TERMS.md`). Amanani nezikrini zokuthenga kuboniswa yisitolo ngasinye. Ukufaka imininingwane yesitolo nezithombe zesikrini kungumsebenzi wesikhathi sokukhishwa, akuyona ingxenye yesakhiwo sendawo. Lo mbhalo awukafakwa kuphaneli yanoma yisiphi isitolo futhi awukabuyekezwa yisikhulumi somdabu sesiZulu. I-App Store Connect ayinikezi isiZulu njengolimi lwemininingwane yesitolo (`appStore: false` ku-`locales/languages.json`); i-Google Play iyasinikeza.

- Igama: **Kagemura: Ninja Clans**
- Isihlokwana se-App Store: **Isigodi se-ninja esifihlekile**
- Incazelo emfushane ye-Google Play: **Yakha isigodi esifihlekile, qeqesha amaqhawe, ugasele izinqaba zezitha**
- Umbhalo wokukhangisa: **Hola isizwe sakho ezivivinyweni Zesithunzi ezingapheli. Intuthu, ukonakalisa necebo kunqoba amandla odwa.**
- Amagama osesho: `ninja,shinobi,isizwe,isigodi,isu,ukugasela,ukuvikela,umbhoshongo,impi,umfelandawonye,inqaba,samurai`

## Incazelo

Hola isizwe se-ninja. Yakha isigodi esifihlekile ezintabeni, uqeqeshe izinhlobo ezingamashumi amahlanu zamaqhawe, uhlole izitha zakho bese uzigasela ngentuthu nangokonakalisa.

**Yakha isigodi sakho esifihlekile**

- Thuthukisa Inqaba Yesizwe kusukela ezingeni 1 kuya ezingeni 15 ukuze uvule izakhiwo ezintsha, izindonga nezivikelo.
- Isakhiwo ngasinye sinomsebenzi waso: Isigayo Sezinhlamvu, Insimu Enezitebhisi, Isikhwama Sezinhlamvu, Idojo Lokuqeqesha, imibhoshongo nezicupho.
- Beka izivikelo zakho ukuze abagaseli kufanele badlule kuzo.

**Qeqesha izinhlobo ezingamashumi amahlanu zamaqhawe**

- Kusukela ku-Shinobi nakoChwepheshe We-Kunai kuya kuMgaseli Wekhayithi, kuMonakalisi nakubaphonsi bamabhomu ezinqabeni: ngamunye unomsebenzi wakhe.
- Ucwaningo eDojweni Lokuqeqesha lwenza iqhawe ngalinye libe namandla kakhulu.

**Gasela ngecebo**

- Amaqhawe angena kuphela ngaMaphuzu Okungena esigodi: hlola izindlela nemibhoshongo ezivikelayo.
- Phonsa Ibhomu Lentuthu lapho amaqhawe akho engena ebangeni lombhoshongo, uthumele uMonakalisi ukuze amise isivikelo.
- Ukuhlasela okuhlelwe kahle kunqoba ibutho elikhulu.

**Dlalani ndawonye** (ku-inthanethi)

- Joyina umfelandawonye: xoxa, cela amaqhawe futhi uwathumele kumalungu esizwe sakho.
- Lwa eMpini Yomfelandawonye njalo ngesonto.
- Engeza abangane, ubaphonsele inselelo eMidlalweni Yobungane, futhi nihlangane emaviyweni abantu abafika kwabane eMpini Yamaviyo.
- Khuphukela emaligini odumo naseHlwini Lwamandla.

**Izivivinyo Zesithunzi**

- Uchungechunge lwezinqaba olungapheli. Izinga ngalinye likhokha kanye kuphela, futhi liba nzima kakhulu.

**Ukudlala ngokulungile**

- Ibhokisi lansuku zonke lamahhala, elikhombisa amathuba alo ngaphambi kokuba ulivule. Akukho okungahleliwe okuthengiswayo.
- Izitha ezenziwe yikhompyutha zihlala zibhalwe kanjalo.
- Imikhawulo yokusebenzisa imali kubadlali abangaphansi kweminyaka eyi-18, nezikhumbuzi ozikhethayo (zivaliwe uze uzivule).

I-Kagemura imahhala ukuyilanda nokuyidlala. Zonke izakhiwo, amaqhawe, amazinga eNqaba nezindlela zokudlala kungafinyelelwa ngaphandle kokukhokha, futhi azikho izikhangiso. Ijeyidi, imali ekhethekile, litholakala kancane ngokudlala (izimpumelelo, amaligi, ibhokisi lansuku zonke nomzila wamahhala woMqulu Wesizini) futhi lingathengwa. Ezinye izinto zithengiswa ngemali yangempela kuphela: umzila okhethekile woMqulu Wesizini (imiklomelo eyengeziwe, ukwakha okusheshayo isizini yonke nokubukeka kweNqaba "Umkhosi Wamalambu") namaphakethe ejeyidi nezinsiza esikhathi esilinganiselwe.

## Izixhumanisi zokukhishwa

Sebenzisa ikheli lomdlalo elishicilelwe, wengeze `/zu/support.html`, `/zu/privacy.html` no-`/zu/community.html`. Ifomu leseva lisekela `/account/delete?lang=zu`. Ukuhunyushwa kwesiZulu kwamakhasi omthetho waseJapane kungu-`/zu/tokushoho.html` no-`/zu/shikin-kessai.html`. Imigomo yesevisi namakhasi omthetho kuseyimibhalo esalungiswa kuze kube yilapho opharetha egcwalisa imininingwane futhi ekusebenzisa. Imithetho yokukhishwa iku-[RELEASE.md](../RELEASE.md).

## Amanothi okukhishwa

I-Kagemura manje iyatholakala ngesiZulu. Izikrini, izifundo, izakhiwo, amaqhawe, izimpi, izaziso namakhasi osizo konke kukhombisa ngesiZulu. Shintsha ulimi ku-Izilungiselelo → Ulimi. Isigodi sakho negama lakho lomdlali kuhlala kunjalo.

Izithombe zesikrini ngesiZulu: `npm run build && npm run store:screenshots -- --language=zu` (kudinga i-Playwright ne-Chromium; uhlelo lungacaciswa nge-`CHROMIUM_PATH`)
