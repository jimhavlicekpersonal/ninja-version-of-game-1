# ข้อมูลร้านค้าภาษาไทย — Kagemura: Ninja Clans

ข้อความที่เตรียมไว้สำหรับ App Store และ Google Play (th-TH) ใช้ภาษาและคำศัพท์เดียวกับในเกม (`locales/th/TERMS.md`) ราคาและหน้าซื้อแสดงโดยแต่ละสโตร์ การเผยแพร่ข้อมูลร้านค้าและภาพหน้าจอเป็นงานตอนเปิดตัว ไม่ได้อยู่ในบิลด์ภายในเครื่อง ข้อความนี้ยังไม่ได้ส่งเข้าคอนโซลของสโตร์ใด และยังไม่ได้รับการตรวจทานจากเจ้าของภาษาไทย

- ชื่อ: **Kagemura: Ninja Clans**
- คำบรรยายรองใน App Store: **หมู่บ้านนินจาลับบนขุนเขา**
- คำอธิบายสั้นใน Google Play: **สร้างหมู่บ้านลับ ฝึกนักรบ และบุกฐานที่มั่นของคู่แข่ง**
- ข้อความโปรโมต: **นำตระกูลของคุณฝ่าบททดสอบเงาที่ไม่มีที่สิ้นสุด ควัน การก่อกวน และไหวพริบชนะพละกำลัง**
- คำค้นหา: `นินจา,ชิโนบิ,ตระกูล,หมู่บ้าน,วางแผน,บุก,ป้องกัน,หอคอย,ปราสาท,สงคราม,พันธมิตร,ป้อม`

## คำอธิบาย

นำตระกูลนินจา สร้างหมู่บ้านลับบนภูเขา ฝึกนักรบห้าสิบชนิด สอดแนมคู่แข่ง แล้วบุกด้วยควันและการก่อกวน

**สร้างหมู่บ้านลับ**

- อัปเกรดป้อมตระกูลจาก Lv 1 ถึง Lv 15 เพื่อปลดล็อกสิ่งก่อสร้าง กำแพง และสิ่งป้องกัน
- สิ่งก่อสร้างแต่ละแห่งมีหน้าที่ของตัวเอง: โรงกษาปณ์ นาขั้นบันได คลัง โดโจฝึกฝน หอคอย และกับดัก
- วางสิ่งป้องกันให้ผู้บุกต้องเดินผ่านหน้า

**ฝึกนักรบห้าสิบชนิด**

- ตั้งแต่ชิโนบิและผู้ชำนาญคุไน ไปจนถึงนักบุกว่าว นักก่อกวน และทหารปืนใหญ่โจมตีป้อม ทุกคนมีบทบาทของตัวเอง
- วิจัยในโดโจฝึกฝนเพื่อให้นักรบแข็งแกร่งขึ้น

**วางแผนแล้วบุก**

- นักรบเข้าได้ทางจุดแทรกซึมเท่านั้น สอดแนมเส้นทางและหอคอยที่คุมทางไว้
- โยนระเบิดควันตอนนักรบเดินเข้าระยะหอคอย และส่งนักก่อกวนไปหยุดสิ่งป้องกัน
- การโจมตีที่คิดมาดีชนะกองทัพที่ใหญ่กว่า

**เล่นร่วมกัน** (ออนไลน์)

- เข้าร่วมพันธมิตรเพื่อแชต ขอและส่งนักรบ
- สู้ในสงครามพันธมิตรทุกสัปดาห์
- เพิ่มเพื่อน ท้าประลอง และรวมก๊วนได้สูงสุด 4 คนเพื่อลงศึกก๊วน
- ไต่ลีกเกียรติและอันดับพลัง

**บททดสอบเงา**

- บันไดป้อมที่ไม่มีที่สิ้นสุด แต่ละชั้นยากขึ้น และแต่ละชั้นจ่ายรางวัลครั้งเดียว

**การเล่นที่ยุติธรรม**

- หีบรายวันฟรีแสดงโอกาสก่อนเปิด ไม่มีการขายสิ่งที่สุ่ม
- คู่ต่อสู้ที่คอมพิวเตอร์สร้างจะติดป้ายไว้เสมอ
- ผู้เล่นอายุต่ำกว่า 18 ปีมีวงเงินใช้จ่าย และการแจ้งเตือนมีเฉพาะที่เลือกเอง ปิดอยู่จนกว่าจะเปิด

Kagemura ดาวน์โหลดและเล่นได้ฟรี สิ่งก่อสร้าง นักรบ เลเวลป้อม และโหมดเกมทั้งหมดใช้ได้โดยไม่ต้องจ่ายเงิน และไม่มีโฆษณา หยกซึ่งเป็นสกุลเงินพรีเมียมหาได้ทีละน้อยจากการเล่น (เป้าหมาย ลีก หีบรายวัน และเส้นทางฟรีของคัมภีร์ซีซัน) และซื้อได้ด้วย เนื้อหาบางส่วนมีขายเท่านั้น: เส้นทางพรีเมียมของคัมภีร์ซีซัน (รางวัลเพิ่ม สร้างเร็วขึ้นตลอดซีซัน และรูปลักษณ์ป้อม “เทศกาลโคมไฟ”) และแพ็กหยกกับทรัพยากรแบบจำกัดเวลา

## ลิงก์สำหรับเปิดตัว

ใช้ที่อยู่ของเกมที่เผยแพร่แล้วต่อด้วย `/th/support.html` `/th/privacy.html` และ `/th/community.html` แบบฟอร์มของเซิร์ฟเวอร์รองรับ `/account/delete?lang=th` คำแปลภาษาไทยของหน้าตามกฎหมายญี่ปุ่นคือ `/th/tokushoho.html` และ `/th/shikin-kessai.html` ข้อกำหนดการให้บริการและหน้าตามกฎหมายยังเป็นร่างจนกว่าผู้ให้บริการจะกรอกข้อมูลและนำมาใช้ ข้อกำหนดการเผยแพร่อยู่ใน [RELEASE.md](../RELEASE.md)

## บันทึกประจำรุ่น

Kagemura รองรับภาษาไทยแล้ว หน้าจอ บทสอน สิ่งก่อสร้าง นักรบ การรบ การแจ้งเตือน และหน้าช่วยเหลือแสดงเป็นภาษาไทย เปลี่ยนภาษาได้ที่ ตั้งค่า → ภาษา หมู่บ้านและชื่อผู้เล่นยังเหมือนเดิม

ภาพหน้าจอภาษาไทย: `npm run build && npm run store:screenshots -- --language=th` (ต้องมี Playwright กับ Chromium และฟอนต์ภาษาไทย ระบุไฟล์โปรแกรมได้ด้วย `CHROMIUM_PATH`)
