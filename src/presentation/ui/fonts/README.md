# Interface font

Self-hosted (Latin subset, woff2) so the installed app works offline; the service worker precaches it with the build. One family for the whole interface: titles and big labels use weights 800–900.

| File | Family | Use | License |
|---|---|---|---|
| `mplus1-latin-var.woff2` | M PLUS 1 (variable, 100–900) | all text: body, numbers, buttons, titles | SIL Open Font License 1.1 (© The M+ FONTS Project Authors) |

It comes from Google Fonts. The OFL allows bundling and redistribution with the game; the font may not be sold on its own. Full license text: https://openfontlicense.org
