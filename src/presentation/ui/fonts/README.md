# Interface fonts

Self-hosted (Latin subset, woff2) so the installed app works offline; the service worker precaches them with the build.

| `shippori-mincho-b1-latin-800.woff2` | Shippori Mincho B1 ExtraBold | titles, big labels, battle timer | SIL Open Font License 1.1 (© The Shippori Mincho Project Authors) |
