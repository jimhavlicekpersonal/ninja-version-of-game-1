Projet soumis à relecture juridique. Les champs vides sont remplis par l'émetteur avant publication.

Le Jade vendu contre de l'argent dans le jeu est un moyen de paiement prépayé pour les biens et services de l'émetteur lui-même. Le Jade obtenu gratuitement en jouant n'en est pas un.

Émetteur
Adresse
ValeurLe nombre de Jade indiqué sur chaque produit (par exemple 100 Jade dans la Bourse de Jade). Aucune limite par achat ni pour le solde ; les joueurs de moins de 18 ans ont une limite de dépenses mensuelle.
ValiditéAucune : le Jade n'expire pas tant que le compte existe.
Où l'utiliserUniquement dans ce jeu, pour les fonctions qui affichent un prix en Jade (compléter des ressources, terminer plus tôt une construction ou un entraînement, et autres).
Consulter le soldeLe compteur de Jade en haut de l'écran du jeu. Pour le solde du Jade acheté, contacte le support.
RemarquesLe Jade ne peut être ni échangé contre de l'argent ni transféré. Il n'est pas remboursé, sauf si la loi l'exige. Le Jade gratuit et le Jade acheté sont affichés ensemble ; le Jade gratuit est compté comme dépensé en premier.
Remboursement en cas de fermetureSi le jeu ferme, ou dans d'autres cas prévus par la loi, le Jade acheté non utilisé est remboursé comme la loi l'exige, avec une annonce dans le jeu au moins 60 jours avant.
