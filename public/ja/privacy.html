年齢層と年少のプレイヤー

Kagemura はアニメ調の戦闘があるストラテジーゲームで、アプリストアでは10代以上向けにレーティングされています。オンラインでプレイする前に、本ゲームは回答を誘導することなく生まれた年（年だけで判断できない場合のみ月も）をお尋ねするか、端末のアプリストアが提供する年齢範囲を使用します。保存するのは結果の年齢層（13歳未満、13〜17歳、18歳以上）だけで、生年月日は保存せず、年齢に合わせてゲームを設定するためだけに使用します：

  • 13歳未満：自由入力のチャットはできず（「がんばって！」などの定型文のみ）、自分で選んだ名前ではなく自動で付けられた名前になり、ほかのプレイヤーは名前で検索できません。プレイ、襲撃、同盟への参加は引き続きできます。
  • 13〜17歳：名前で検索できるのはフレンドのフレンドだけで、フレンドには最後にオンラインだった時間が表示されません（設定で変更するまで）。
  • 18歳未満（上記の両方の年齢層）：月間の支出上限、購入前の「大人の人に確認しよう」という追加の確認があり、自動で表示される期間限定オファーはありません。

年齢層はお客様ご自身の申告であり、年齢確認ではありません。一度18歳未満と申告すると、本ゲームが自動で成人に戻すことはできません。当社のサポートチームが確認のうえ変更できます。保護者の方で、お子様が誤った年齢を申告した、または個人情報を共有したと思われる場合は、当社までご連絡ください。アカウントの削除を含めてお手伝いします。これらの保護は、それを含めてリリースされたバージョンの本ゲームに適用されます。古いバージョンでは、初回購入の前にのみ年齢層をお尋ねします。

オンラインプレイなしで遊ぶ場合

村は端末に保存されます。本ゲームにアカウントは不要で、オンラインプレイがオフの場合、お客様に関する情報を当社に一切送信しません（下記のクラッシュレポートをオンにした場合を除きます）。設定に表示されるプレイ統計（「分析イベント」）は端末内にとどまります。ただし、オンラインでプレイする成人の方が共有を選んだ場合を除きます（下記）。ウェブブラウザで遊ぶ場合、本ゲームを配信するウェブサイトは、ほかのウェブサイトと同様に IP アドレスを確認します。

プレイ統計（同意しない限りオフ、成人のみ）

オンラインでプレイし、成人であると申告した場合、本ゲームはプレイ統計を共有するかどうかを一度だけお尋ねします。設定にも同じスイッチがあります。同意するまではオフで、18歳未満のプレイヤーや年齢が不明なプレイヤーには、尋ねることも統計を送信することもありません。オンの場合、本ゲームはお客様のゲーム内での行動（セッションの開始、チュートリアルの進行、星と破壊率を含む襲撃、開始した強化と研究、表示されたオファー、時間短縮に使った翡翠、商品と価格を含む購入）を、この目的のために作られたランダムな統計 ID のもとで送信します。統計 ID はプレイヤー ID とは異なり、一緒に送信されることはありません。本ゲームは名前、村、チャット、サインイントークンを追加せず、当社サーバーは IP アドレスをそれらと一緒に保存しません。同意すると、この端末がそれ以前に記録した内容も送信されます（プレイの最初の数分を確認できるようにするため）。スイッチをオフにすると、その統計 ID が送信した内容は削除され、再び同意すると新しい統計 ID が作られます。共有された統計は400日間保存し、合計値（たとえば、新しいプレイヤーのうち翌日に戻ってきた人数）にのみ使用します。共有しているプレイヤーには、どちらがより効果的かを比較するため、ゲーム内オファーのタイミングがわずかに異なる場合があります。価格、報酬、ゲームのルールは全員同じです。

クラッシュレポート（オンにしない限りオフ）

クラッシュレポート機能を含むバージョンの本ゲームでは、設定に「クラッシュレポートを送信する」スイッチがあります。オンにするまではオフです。オンの状態で本ゲームにエラーが発生すると、エラーメッセージ、本ゲームのコード内の発生箇所、ゲームのバージョン、プラットフォームを、当社のエラー追跡サービス（Sentry）に送信します。本ゲームは名前、プレイヤー ID、村、チャット、セーブデータを添付せず、メッセージからウェブアドレスのパラメーターやメールアドレスのような文字列を削除します。それでも、エラーメッセージに、失敗時に本ゲームが処理していたテキストがまれに含まれることがあります。このサービスはレポートの送信元の IP アドレスを確認できますが、当社は IP アドレスを保存しないよう設定しています。スイッチをオフにすると、新しいレポートはすぐに停止します。

アカウントの削除

  • ゲーム内：設定 → オンラインプレイ → アカウント → オンラインアカウントを削除。
  • ゲームを開けなくなった場合はウェブで：。プレイヤー ID と削除コードを入力してください。削除コードは、ゲームを使えるうちに設定 → オンラインプレイ → アカウントで取得できます（1回限り、30日間有効です。再度取得すると置き換わり、当社は一方向ハッシュのみを保存します）。コードがあれば、当社はリクエストを実行します。コードがない場合は、プレイヤー ID と名前はほかのプレイヤーにも見えるため、まずリクエストがアカウントの所有者からのものであることを確認する必要があります。リクエストは30日以内に実行します。
