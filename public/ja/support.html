お問い合わせ

メール：

オンラインでプレイしている場合はプレイヤー ID（設定 → オンラインプレイ → アカウント）を、購入については日付とストアの注文番号を記載してください。セーブコードや他人のパスワードは絶対に送らないでください。

村がなくなった、または表示がおかしい

  • 村はこの端末に保存されています。本ゲームがセーブデータを読み込めなかった場合はそれを保存しています。設定で以前の村を探し、「復元」をタップしてください。
  • 村を別の端末に移すには、古い端末で設定 →セーブコードをコピーを、新しい端末でコードから読み込むを使ってください。当社サーバーに保存された村は、連携したサインイン方法で新しい端末にサインインすると戻ってきます（設定 → オンラインプレイ → アカウント → サインイン方法）。
  • 村が別の場所で開いていますと表示された場合は、もう一方のタブやアプリを閉じてください。保存されるのは最後に開いたものだけです。

購入

  • 購入品が届かない場合は、オンラインの状態でショップを開き、購入を復元をタップしてください。保護者の承認やストアの処理を待っている購入は、承認されると届きます。
  • 返金は Apple または Google が対応します。App Store または Google Play の購入履歴から各社にお問い合わせください。ストアが購入を返金した場合、当社サーバーに保存された村から、その購入で得たものが取り消されることがあります。
  • 18歳未満のプレイヤーには月間の支出上限があります。誤って18歳未満と申告した場合は、プレイヤー ID を添えてご連絡ください。本ゲームが自動で成人に戻すことはできません。
  • ウェブ版の本ゲームでは何も販売していません。
  • 翡翠には換金価値がなく、有効期限もありません。利用規約をご覧ください。日本のプレイヤーの皆様へ：特定商取引法に基づく表記 · 資金決済法に基づく表示。

オンラインプレイ

  • 接続なし：建設は続けられます。村が当社サーバーに保存されている場合、本ゲームは操作を保存し、オンラインに戻ったときに送信します。本物のプレイヤーへの襲撃、同盟、フレンド、購入には接続が必要です。
  • アップデートが必要：ストアから最新バージョンをインストールするか、ウェブページを再読み込みしてください。
  • 利用停止またはチャット停止：アカウントがコミュニティルールに違反しました。本ゲームがその理由と期間をお知らせします。異議を申し立てるには、6か月以内にプレイヤー ID を添えてご連絡ください。最初の決定に関わっていない者が改めて確認します。
  • 年齢層：本ゲームはオンラインプレイの前に一度だけ生まれた年をお尋ねし、年齢層だけを保存します。13歳未満のプレイヤーは定型文でのみチャットでき、自動で付けられた名前になり、名前で検索されません。13〜17歳のプレイヤーは、最初は知らない人から見えず、オンライン状態もオフになっています。本ゲームでは年齢層を厳しくすることしかできません。お子様が誤った年齢を申告した場合は、保護者の方からご連絡ください。

ほかのプレイヤーに困らされている

同盟や徒党のチャットのメッセージ、同盟のメンバー一覧、フレンドカードの横にある⋯をタップして、報告またはブロックできます。ブロックすると、相手のチャットやリクエストがすぐに表示されなくなります。報告について当社が決定した内容はお知らせしますが、誰が報告したかを相手に伝えることはありません。コミュニティルールをご覧ください。誰かに危険が迫っている場合は、まず地域の緊急通報先に連絡してください。

安全性や私たちの判断についての苦情

違法なコンテンツ、子どもに有害なコンテンツ、モデレーションの判断（削除されたメッセージ、チャット停止、利用停止、対応しなかった報告）、ゲームが使う年齢区分、または英国のオンライン安全法を含むオンライン安全上の義務への私たちの対応について、苦情を申し立てることができます。アカウントは必要ありません。上記のアドレスに、件名をオンライン安全に関する苦情として、何があったか、オンラインでプレイしている場合はプレイヤー ID を添えてメールしてください。受け付けたことをお知らせし、最初の判断に関わっていない者が確認して、結果をお伝えします。私たちが誤っていた場合は、メッセージやアカウントを元に戻します。

アカウントの削除

ゲーム内：設定 → オンラインプレイ → アカウント →オンラインアカウントを削除。ゲームを使わない場合：で、プレイヤー ID または名前と削除コードを入力してください。削除コードは、ゲームを使えるうちに設定 → オンラインプレイ → アカウントで取得できます（1回限り、30日間有効）。コードがない場合は、まずアカウントがご本人のものであることを確認する必要があります。端末上の村は、アプリをアンインストールするか、サイトのデータを消去すると削除されます。詳しくはプライバシーポリシーをご覧ください。
