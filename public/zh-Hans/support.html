如果你在线游戏，请附上你的玩家 ID（设置 → 在线游戏 → 账号）；如果是购买问题，请附上日期和商店的订单号。绝不要发送你的存档代码或任何人的密码。

我的村庄不见了或显示不对

  • 你的村庄保存在此设备上。如果游戏无法读取某个存档，它会将其保留：在“设置”中找到以前的村庄，然后点“恢复”。
  • 要把村庄转移到另一台设备，请在旧设备上使用“设置 → 复制存档代码”，在新设备上使用从代码载入。保存在我们服务器上的村庄，会在你用已关联的登录方式（设置 → 在线游戏 → 账号 → 登录方式）在新设备上登录时回来。
  • 如果游戏提示村庄已在别处打开，请关闭另一个标签页或应用：只有最后打开的那个会保存。

购买

  • 如果某笔购买没有到账，请在联网时打开商店并点恢复购买。等待家长批准或商店处理的购买会在批准后到账。
  • 退款由 Apple 或 Google 处理：请通过你的 App Store 或 Google Play 购买记录向它们申请。商店退款后，该购买所给的物品可能会从保存在我们服务器上的村庄中收回。
  • 未满 18 岁的玩家有每月消费限额。如果你误报自己未满 18 岁，请附上你的玩家 ID 写信给我们：游戏无法自行改回成年人。
  • 游戏的网页版不出售任何东西。
  • 翡翠没有现金价值，也不会过期；见服务条款。日本玩家请见：依据日本《特定商业交易法》的标示 · 依据日本《资金结算法》的标示。

在线游戏

  • 无网络连接：你可以继续建造；如果你的村庄保存在我们的服务器上，游戏会保存你的操作，并在你恢复联网后发送。突袭真实玩家、同盟、好友和购买都需要联网。
  • 需要更新：从你的应用商店安装最新版本，或重新载入网页。
  • 被暂停或禁言：该账号违反了社区规则。游戏会告诉你原因和期限。如需申诉，请在六个月内附上你的玩家 ID 写信给我们：会由未参与最初决定的人重新审核。
  • 年龄段：游戏会在在线游戏前询问一次出生年份，并且只保存年龄段。未满 13 岁的玩家只能用固定短语聊天，会获得游戏生成的名称，也无法被按名称找到；13 至 17 岁的玩家开始时对陌生人隐藏，在线状态也关闭。游戏只能把年龄段改得更严格；如果你的孩子提供了错误的年龄，请家长写信给我们。

有人在骚扰我

在同盟或帮派聊天中对方的消息旁、同盟成员列表中或好友卡片上点⋯，即可举报或屏蔽对方。屏蔽会立即对你隐藏对方的聊天和请求。我们会告诉你我们对举报的处理决定，并且绝不会告诉对方是谁举报的。见社区规则。如果有人身处危险，请先联系当地的紧急服务。

删除我的账号

在游戏中：设置 → 在线游戏 → 账号 → 删除在线账号。没有游戏时：，提供你的玩家 ID 或名称以及删除码：趁你还能使用游戏时，在“设置 → 在线游戏 → 账号”中获取一个（只能使用一次，有效期 30 天）。没有删除码时，我们必须先核实该账号属于你。设备上的村庄会在你卸载应用或清除网站数据时删除。详情见隐私政策。
