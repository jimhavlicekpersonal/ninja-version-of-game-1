年龄段与年幼玩家

Kagemura 是一款带有卡通战斗的策略游戏，在应用商店中的分级为青少年及以上。在你在线游戏之前，游戏会询问你的出生年份（只有仅凭年份无法确定时才会询问月份），且不会暗示答案；或者使用你设备的应用商店提供的年龄范围。游戏只保存由此得出的年龄段（未满 13 岁、13 至 17 岁、18 岁或以上），不保存你的出生日期，并且只用它来按你的年龄设置游戏：

  • 未满 13 岁：不能自由输入聊天内容（只能使用一组固定短语，例如“祝好运！”），使用游戏生成的玩家名称而不是自选名称，其他玩家也无法按名称找到你。你仍然可以游戏、突袭和加入同盟。
  • 13 至 17 岁：只有好友的好友可以按名称找到你，好友也看不到你上次在线的时间，除非你在“设置”中更改。
  • 未满 18 岁（以上两个年龄段）：每月消费限额，购买前额外的“先问问大人”步骤，并且不会自动弹出限时优惠。

年龄段是你本人的声明，而不是年龄验证。一旦你表示自己未满 18 岁，游戏就不能自行把你改回成年人；我们的客服团队在核实后可以更改。如果你是家长，认为孩子提供了错误的年龄或分享了个人信息，请写信给我们，我们会提供帮助，包括删除该账号。这些保护措施适用于包含它们的游戏版本；较早的版本只会在首次购买前询问年龄段。

不使用在线游戏时

你的村庄保存在你的设备上。游戏不需要账号，关闭在线游戏时，它不会向我们发送任何关于你的信息（除非你开启下文所述的崩溃报告）。“设置”中显示的游戏统计（“统计事件”）保留在设备上，除非你是在线游戏的成年人并选择分享（见下文）。如果你在网页浏览器中游戏，提供游戏的网站会看到你的 IP 地址，所有网站都是如此。

我们收集什么、为什么收集，以及法律依据

法律依据为欧盟和英国 GDPR（第 6 条）以及巴西 LGPD（第 7 条）的规定。“合同”指我们需要这些数据来提供你要求游玩的游戏；“正当利益”指我们已权衡我们的理由与你的权利，你可以提出反对（见“你的权利”）。

在线账号：随机玩家 ID、一个秘密登录令牌（我们只保存其单向哈希值）、你选择的名称、你的好友码、你的年龄段、你的隐私选择、你上次在线的时间用于运行你的在线账号、向其他玩家显示你的名称，并为你的年龄段应用保护措施。依据：合同；年龄段还基于法律义务和正当利益（保护年幼玩家）。LGPD：履行合同、法律义务。
你的游戏：你用于突袭的基地、保存在我们服务器上的村庄及你在其中的操作、战斗和回放、荣誉、排名和评分、资源增减的历史记录使在线游戏正常运作、突袭经过核验且公平，并让你可以在另一台设备上继续游戏。依据：合同；核验战斗以防作弊属于正当利益。
社交功能：同盟和帮派聊天消息、战士请求和赠送、好友和好友请求、帮派、帮派战和友谊切磋用于提供这些功能。依据：合同。
安全：你提交的举报（理由、可选备注，以及聊天消息被发送时的原文）、屏蔽、禁言和暂停，以及我们就此发送给你的通知（保存在你的账号中，直至账号被删除）用于维护社区安全、处理举报、告知举报人和受影响的玩家我们的决定，以及处理申诉。依据：正当利益（让所有人都能安全游戏），以及在网络安全法律要求时的法律义务。
你关联的登录方式（可选）：Apple、Google 或 Game Center 为你提供给我们的 ID；对于“通过 Apple 登录”，还包括 Apple 向游戏签发的令牌；你的每台设备使用了哪种登录方式以及上次使用的时间用于在另一台设备上恢复你的账号、在你取消关联某种登录方式时让设备退出登录，以及在你删除账号或取消关联 Apple 时撤销游戏在 Apple 的访问权限。我们从不接收或保存它们提供的你的电子邮件地址或姓名。依据：合同，应你的请求。
购买：商店的交易 ID、商品、价格、日期和退款状态用于每笔购买只发放一次、恢复购买、处理退款以及应用未满 18 岁限额。依据：合同和法律义务（税务和会计记录）。
通知（可选）：你设备的通知令牌、你选择的类型以及你的时区偏移用于只发送你开启的通知，绝不在夜间或过于频繁地发送。依据：同意（由你开启，也可以关闭）。
网络数据：你每次向我们服务器发出请求时的 IP 地址用于阻止滥用（频率限制）并保障服务安全。只保存在短期计数器和服务器日志中。我们不会用它来推断你的位置。依据：正当利益（安全）。
服务器错误报告：错误、路由，以及请求方法和路径（不含查询字符串或请求内容）用于修复我们服务器的故障。依据：正当利益。
游戏的崩溃报告（可选，见下文）用于修复崩溃。依据：同意。
游戏统计（可选，仅限成年人，见下文）：你在游戏中的操作，以随机统计 ID 记录用于了解玩家在哪里卡住，以及改动是否有帮助。依据：同意。

如果你让游戏查找你的 Game Center 好友，我们会使用他们的 ID 查看一次其中谁在玩 Kagemura；我们不会保存该名单。我们不会通过自动化方式对你作出具有法律效力或类似重大影响的决定。只有一项自动安全措施：被三名不同玩家举报的聊天消息会被隐藏，直至我们的工作人员查看。

游戏统计（除非你同意，否则关闭；仅限成年人）

当你在线游戏并告诉我们你是成年人时，游戏会询问一次你是否愿意分享游戏统计；“设置”中也有相同的开关。在你同意之前它是关闭的，对于未满 18 岁或年龄未知的玩家，游戏从不询问，也从不发送统计数据。开启后，游戏会以专门为此生成的随机统计 ID 发送你在游戏中的操作（开始游戏会话、教程步骤、突袭及其星数和摧毁率、开始的升级和研究、显示的优惠、用于加速的翡翠，以及购买及其商品和价格）。统计 ID 不是你的玩家 ID，也从不与之一起发送；游戏不会附加你的名称、村庄、聊天内容或登录令牌，我们的服务器也不会将 IP 地址与之一起保存。同意后还会发送此设备之前记录的内容（以便我们了解游戏开始的头几分钟）。关闭开关会删除该统计 ID 已发送的内容；再次同意会开始一个新的统计 ID。我们会将分享的统计数据保存 400 天，并且只以汇总形式使用（例如，有多少新玩家第二天回来）。参与分享的玩家可能会遇到时机略有不同的游戏内优惠，以便比较哪种效果更好；价格、奖励和游戏规则对所有人都相同。

崩溃报告（除非你开启，否则关闭）

包含崩溃报告功能的游戏版本会在“设置”中显示“发送崩溃报告”开关。在你开启之前它是关闭的。开启后，如果游戏出错，游戏会将错误信息、出错的游戏代码位置、游戏版本和平台发送到我们的错误追踪服务（Sentry）。游戏不会附加你的名称、玩家 ID、村庄、聊天内容或存档，并会从信息中移除网址参数和任何形似电子邮件地址的内容。错误信息偶尔仍可能包含游戏出错时正在处理的文字。该服务会看到报告来源的 IP 地址；我们已将该服务设置为不保存 IP 地址。关闭开关会立即停止发送新的报告。

举报、管理与通知

当你举报一条消息或一名玩家时，我们的工作人员会进行审核，并可以删除消息、禁言或暂停账号（见社区规则）。我们会告诉举报的玩家处理结果；当我们删除某名玩家的消息、对其禁言或暂停其账号时，也会告知该玩家原因以及如何申诉。我们不会告诉被举报的玩家是谁举报的。工作人员的每项操作都会被记录，以便核查决定。

当你联系我们时

  • 客服邮件。如果你写信给我们，我们会收到你的电子邮件地址和你发送的内容，并且只用它们来回复你和保留该回复的记录。
  • 网页删除请求。账号删除页面会要求你提供玩家 ID、游戏给你的删除码以及一条可选备注。它不会要求电子邮件地址。我们会保存该请求及我们的处理情况，作为已处理的记录。

我们不做什么

我们不会在游戏中索取你的电子邮件地址，也不会收集你的通讯录、精确位置、照片或广告标识符。没有广告，也没有第三方追踪，我们不会出售你的数据，也不会为广告或跨情境行为广告分享你的数据。

谁来处理数据，在哪里处理

我们使用只按照我们的指示处理数据的服务提供商：我们的托管服务提供商（服务器和数据库：）、我们的错误追踪服务 Sentry（仅在你开启时处理崩溃报告，以及我们服务器自身的错误；数据区域：），以及 Apple 和 Google（登录、购买和通知，适用它们各自的隐私政策）。我们的工作人员只查看他们回复客服和进行管理所需的内容。

其中一些服务提供商可能在你所在国家/地区以外处理数据，包括欧盟、英国或巴西以外。当数据从欧盟或英国转移到没有充分性认定的国家/地区时，我们依据欧盟委员会的标准合同条款（以及英国附录或国际数据传输协议）或法律允许的其他传输机制。你可以向我们索取相关保障措施的副本。

删除你的账号

  • 在游戏中：设置 → 在线游戏 → 账号 → 删除在线账号。
  • 如果你已无法打开游戏，可以在网页上删除：。输入你的玩家 ID 和删除码：趁你还能使用游戏时，在“设置 → 在线游戏 → 账号”中申请一个（它只能使用一次，有效期 30 天；再次申请会替换旧的，我们只保存它的单向哈希值）。有删除码时我们会直接执行请求；没有删除码时，我们必须先确认请求来自账号的所有者，因为玩家 ID 和名称对其他玩家可见。我们会在 30 天内执行请求。

你的权利

无论你住在哪里，你都可以要求我们：

  • 访问你的数据并获取副本，并以常用的机器可读格式接收你提供给我们的数据（可携带性）；
  • 更正数据，或删除数据（见上文）；
  • 在问题解决期间限制我们使用数据的方式，并反对基于正当利益的使用；
  • 随时撤回同意（崩溃报告、游戏统计、通知：在“设置”中），不影响此前已发生的处理。关闭游戏统计还会删除已分享的内容。

请附上你的玩家 ID 写信至 。我们会在一个月内答复（在巴西，在 LGPD 规定的期限内；在加利福尼亚州，在 45 天内），并且可能需要先确认该账号属于你。你也可以向数据保护机构投诉：在欧盟，向你居住或工作地的机构投诉；在英国，向信息专员办公室（ico.org.uk）投诉；在巴西，向 ANPD（gov.br/anpd）投诉。加利福尼亚州居民享有 CCPA/CPRA 规定的权利，包括知情、删除、更正以及不因行使这些权利而受到歧视的权利；按照这些法律的定义，我们不出售或分享个人信息。根据 LGPD，你还可以要求确认我们是否处理你的数据、进行匿名化处理、了解我们与谁分享数据，以及拒绝同意的后果。

购买

购买通过 App Store 或 Google Play 进行。它们处理你的付款信息；我们从不会看到这些信息。服务条款介绍了翡翠和其他购买。

安全

游戏只通过加密连接（HTTPS）与我们的服务器通信，登录令牌以单向哈希值保存，工作人员的访问受到限制并被记录。没有任何系统是绝对安全的；如果发生影响你的数据泄露，我们会按照法律要求通知你和有关机构。

变更

当我们收集的内容发生变化时，我们会更新本页面及其日期，并在游戏中告知玩家重要的变更。
