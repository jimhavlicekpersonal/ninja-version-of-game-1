# ગુજરાતી: પસંદ કરેલા શબ્દો

રોજિંદી, સરળ ગુજરાતી; ભારે સંસ્કૃતપ્રધાન નહીં. ખેલાડીને "તમે" કહેવામાં આવે છે અને બટન ટૂંકા આજ્ઞાર્થ કે નામરૂપે હોય છે (બનાવો, અપગ્રેડ, લો). ખેલાડી કે {name} સાથે લિંગ પ્રમાણે બદલાતું ક્રિયાપદ ક્યારેય નહીં (ભૂતકાળ "જીત્યો/જીતી" ટાળો: "વિજય: {name}" અથવા "{name}એ જીત મેળવી"). "તમે" સાથે આદરવાચક બહુવચન રૂપ (તમે જીત્યા) લિંગ-નિરપેક્ષ છે. ટેક્સ્ટ Unicode NFC માં.

બહુવચન: one (0 અને 1) અને other. સંખ્યા નામ પહેલાં ({n} યોદ્ધા). અનુગો (નું, ને, માં, થી) placeholder સાથે જોડાય છે ({name}નું ગામ); "નું/ની/નો" માલિકીની વસ્તુ સાથે મેળ ખાય છે, placeholder સાથે નહીં.

બનાવેલાં નામ (generatedNames): મૂળભૂત ક્રમ, પહેલો ભાગ, જગ્યા, બીજો ભાગ (ગર્જના શિખર). ગુજરાતીમાં વિશેષણ નામની પહેલાં આવે છે. પહેલા ભાગ અવિકારી વિશેષણ કે નામ છે (ગર્જના, શાંત, જોડિયા), જે દરેક બીજા ભાગ (નામ) સાથે બંધબેસે; "નું/ની" ઉમેર્યું નથી.

આ અનુવાદની મૂળ ગુજરાતી ભાષી વ્યક્તિએ હજુ સમીક્ષા કરી નથી.
